# Early Diabetes Prediction System

## Project Overview
The Early Diabetes Prediction System is a Machine Learning project that predicts whether a person is likely to have diabetes based on medical data. The project uses the Pima Indians Diabetes Dataset and the Random Forest Classifier algorithm.

## Features
- Data Preprocessing
- Feature Scaling
- Machine Learning Model Training
- Diabetes Risk Prediction
- Model Saving using Joblib

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib

## Dataset
Pima Indians Diabetes Dataset

## Machine Learning Algorithm
Random Forest Classifier

## Model Accuracy
Approximately **72.73%**
